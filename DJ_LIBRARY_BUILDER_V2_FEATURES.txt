              DJ LIBRARY BUILDER v2 - CHECKPOINT & RESUME SYSTEM

Major Upgrade: Stop & Resume Anytime Without Losing Progress

================================================================================
WHAT'S NEW IN v2
================================================================================

✅ CHECKPOINT SYSTEM
   - Saves progress after every track processed
   - Remembers which tracks are done
   - Can stop and resume 100% of work

✅ RESUME FROM ANYWHERE
   - Stop processing anytime
   - Restart the app hours/days later
   - Pick up exactly where you left off

✅ SKIP COMPLETED TRACKS
   - Already-processed tracks are skipped automatically
   - No re-recording or re-processing
   - Saves time on resume

✅ GRACEFUL STOP
   - Click "STOP" button to pause
   - Session saved automatically
   - "RESUME SESSION" button appears next restart

✅ MULTIPLE SESSIONS
   - Process one playlist, then another
   - Each has its own session folder
   - Clear old sessions anytime

================================================================================
HOW IT WORKS
================================================================================

FIRST TIME:
  1. Paste playlist URL
  2. Click "START NEW SESSION"
  3. Let it record and process
  4. At any point, click "STOP"
  5. Progress saved ✓

NEXT TIME:
  1. Open app
  2. App shows "Found resumable session"
  3. Shows: 67/300 tracks completed
  4. Click "RESUME SESSION"
  5. Continues from track 68
  6. Skips all 67 completed tracks

================================================================================

MONDAY 6 PM:
  - Start: "START NEW SESSION"
  - Let it run 4 hours

  - Session saved ✓

TUESDAY 8 AM:

================================================================================
SESSION STRUCTURE
================================================================================

~/.dj_builder_cache/sessions/
  20240101_120000/          <- Session ID (date_time)
    progress.json           <- Current state (which tracks done, etc)
    recording.wav           <- Full audio recording (kept as backup)
    track_001.wav           <- Split audio files
    track_002.wav
    ...
    playlist_metadata.json  <- All track info

When you resume, app reads progress.json to see which tracks are done.

================================================================================
PROGRESS TRACKING
================================================================================

progress.json contains:

{
  "playlist_url": "https://music.apple.com/us/playlist/...",
  "total_tracks": 300,
  "completed_tracks": [0, 1, 2, ...],     <- Track indices (0-based)
  "failed_tracks": [...],                 <- Failed tracks with errors
  "current_phase": "processing",          <- idle, recording, processing, done
  "started_at": "2024-01-01T18:00:00",
  "last_updated": "2024-01-02T08:00:00",
  "recording_file": "...",
  "split_files": [...]
}

App reads this on startup to:
  1. Detect if session can be resumed
  2. Skip already-completed tracks
  3. Show progress percentage
  4. Show how many tracks remaining

================================================================================
STOPPING & RESUMING
================================================================================

WHEN YOU CLICK "STOP":
  ✓ Recording stops immediately (or continues if already recording)
  ✓ Processing stops between tracks
  ✓ Partial track might not be completed
  ✓ Session saved to progress.json
  ✓ "RESUME SESSION" button appears next time

WHEN YOU RESUME:
  ✓ App detects previous session
  ✓ Loads progress.json
  ✓ Shows how many completed
  ✓ Skips all completed tracks
  ✓ Continues with remaining

NO RE-RECORDING NEEDED:
  ✓ Recording is already done (saved as recording.wav)
  ✓ Split files exist (track_001.wav, etc)
  ✓ Only need to transcode remaining tracks

================================================================================
CLEARING SESSIONS
================================================================================

Each session takes ~10 GB disk space (recording + temp files + tracks).

Clear old session from app:
  - Click "Clear Session" button
  - Deletes that session's folder

Clear all sessions from Terminal:
  bash
  rm -rf ~/.dj_builder_cache/sessions/*

This keeps final tracks in ~/Music/DJ-Library/ (those don't get deleted).

================================================================================
ERROR HANDLING
================================================================================

If a track fails to process:
  ✓ Error logged to progress.json
  ✓ Track marked as "failed"
  ✓ Processing continues with next track
  ✓ Can retry failed tracks on resume

If app crashes:
  ✓ Progress saved up to last checkpoint
  ✓ Restart app
  ✓ Click "RESUME SESSION"
  ✓ Continues from checkpoint
  ✓ No work lost

If recording file deleted:
  ✗ Need to re-record (can't resume that part)
  ✓ All processed tracks still in ~/Music/DJ-Library/

================================================================================
TECH DETAILS
================================================================================

progress_tracker.py:
  - Tracks completion state
  - Saves checkpoints to progress.json
  - Loads previous sessions
  - Calculates progress %

processor.py updates:
  - Checks progress before processing each track
  - Skips completed tracks
  - Saves checkpoint after each track completes
  - Can resume from any checkpoint

dj_library_builder.py updates:
  - Detects resumable sessions on startup
  - Shows "RESUME SESSION" button if available
  - Allows starting new or resuming old
  - Stops gracefully when user clicks STOP
